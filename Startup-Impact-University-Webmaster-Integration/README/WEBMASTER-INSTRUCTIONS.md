# Startup Impact — University Webmaster Integration

## Your only task

Add a menu item to the University website:

**Startup Impact**

Point it to the University-specific Startup Impact URL supplied by the Startup Impact administrator.

Example:

`https://startupimpact.example.com/u/<university-slug>`

## Important

You do NOT need:
- Startup Impact source code
- Startup Impact database
- scoring/valuation methodology
- admin credentials
- server credentials

Startup Impact is independently hosted and updated centrally.

## Navigation back to the University

The Startup Impact application stores the University's official website URL. Its **Back to University** link returns visitors to the University website.

## If the Startup Impact application is updated

Normally, the University website menu link does not need to be changed. Updates are made on the Startup Impact server.

## Do not embed or copy the application source unless specifically instructed.

This integration package is intentionally minimal.
