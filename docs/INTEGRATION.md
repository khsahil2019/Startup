# University Website Integration

Preferred:
`<script src="https://YOUR-HOST/embed.js" data-university="UNIVERSITY-SLUG"></script>`

Alternative:
`<iframe src="https://YOUR-HOST/u/UNIVERSITY-SLUG" style="width:100%;min-height:2200px;border:0"></iframe>`

Or add a normal top-menu link to the live `/u/:slug` page.

The university developer does not receive a new static HTML file for every startup update. The public page reads the verified live record.
