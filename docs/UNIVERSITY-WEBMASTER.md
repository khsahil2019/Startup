# University Webmaster — Startup Impact Integration

The University webmaster does not need the Startup Impact source code, database, scoring logic or administrative credentials.

## One-time task
Add a menu item named **Startup Impact** to the University website and point it to the University's Startup Impact URL.

Example:
`https://startupimpact.example.com/u/<university-slug>`

After this one-time link is added, Startup Impact is updated centrally. The University website does not need a new code deployment for normal Startup Impact feature/content updates.

The Startup Impact application stores the University's official website URL and uses it for the **Back to University** navigation.
